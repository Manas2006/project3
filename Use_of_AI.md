# Use of AI

I used AI assistance (GPT) for two very minor purposes only. All code was written by me.

## [1] Git command help
- **Tool**: GPT
- **Prompt**: I asked for exact git commands for basic git operations, specifically:
  - How to initialize a repository
  - Commands for committing and pushing changes
  - How to pull with rebase to avoid merge commits
  - How to handle merge conflicts, especially with binary files like notebook outputs
  - How to stash changes temporarily before pulling
  - How to resolve conflicts when git reports unstaged changes
- **Output used**: Received command sequences and explanations for git workflow operations. No code was generated - only command-line instructions for version control.
- **How it was used**: I used these git command references to manage the repository workflow throughout the project. All actual code, notebooks, and implementation were written by me independently.

## [2] Project structure guidance
- **Tool**: GPT
- **Prompt**: I asked for high-level suggestions on how to structure a three-notebook machine learning project. Specifically requested:
  - What folders and files should be included (e.g., data/, models/, notebooks/, README.md)
  - How to organize a pipeline across multiple Jupyter notebooks
  - Best practices for saving datasets and model checkpoints
  - How to structure the project directory for clarity
- **Output used**: Received general folder structure recommendations and organizational suggestions. These were high-level architectural ideas only (e.g., "use a data/ folder for datasets", "separate notebooks by stage of the pipeline").
- **How it was used**: I used these suggestions as a starting point for organizing my project structure. However, I designed and created all the actual code, notebook content, implementation details, functions, evaluation logic, and all other aspects of the project myself. The AI assistance was purely organizational guidance at the project structure level.
